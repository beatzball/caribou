The nav rail draws its icons with `<caribou-icon>`, and New post is a
`<caribou-button variant="primary">`. `<caribou-button>` gains a `label`
attribute that names its inner button, so a button whose text is hidden at
narrow widths keeps an accessible name. The pen icon moves into the shared
icon set as `squarePen`.
