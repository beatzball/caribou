Bluesky is on for everyone. The landing page shows the Mastodon and Bluesky sign-in panels to every visitor, with no browser flag. The server renders Bluesky profiles and posts by default. Set `BLUESKY_SSR` to `0`, `false`, `off` or `no` to turn that off; the server logs which it is at start. A tab chosen or a handle typed while the page loads is kept.
