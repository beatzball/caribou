A post's author is now a link. A click on the avatar, the display name or the @handle opens the author's profile inside Caribou, without a full page load. On a boost, the booster's name in the "boosted" line opens the booster's profile. The author block is one real link: middle-click, Cmd-click, copy-link and no-JavaScript all work, a keyboard user tabs to it once, and a screen reader hears the display name.
