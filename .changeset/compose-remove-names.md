Compose: each attached file's Remove button, Retry button and alt text field now has its own name for screen readers. The name gives the place and the file name, such as "Remove image 2, photo.jpg" and "Alt text for image 2, photo.jpg". Two files with the same name still get different names. A draft saved before this change has no file names, so its controls say "Remove image 1", "Remove video 2" and so on. The visible text is still "Remove".
